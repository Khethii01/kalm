# Brand logo assets

Place the **original, unmodified** logo files supplied by KALM Group here. The
website references these exact filenames. Do **not** recolour, redraw, stretch
or replace them with approximations — optimise for web only (e.g. export a
reasonably sized PNG/WebP while preserving proportions).

| File                     | Used for                                   | Notes                                                        |
| ------------------------ | ------------------------------------------ | ------------------------------------------------------------ |
| `kalm-logo.png`          | Primary brand identity (header, footer)    | The full "KALM GROUP" lockup on deep-navy background.        |
| `kalm-mark.png`          | Optional: compact mark only (favicon-like) | Optional. If absent, the full logo is used everywhere.       |
| `puma-energy.png`        | Secondary partner asset only               | Keep original red/green/white colours and proportions.       |

## How the site behaves before you add these files

Until `kalm-logo.png` and `puma-energy.png` exist here, the site shows an
accessible text + mark fallback so nothing looks broken. Once you drop the real
files in with the names above, they appear automatically — no code changes
needed.

## Recommended export

- `kalm-logo.png`: transparent background preferred, or keep the navy backdrop.
  Target ~600px wide, under ~120 KB.
- `puma-energy.png`: transparent background preferred. Target ~400px wide.
